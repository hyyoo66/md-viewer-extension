# MD 뷰어 → PDF / Word

탐색기에서 `.md` 파일을 **더블클릭**하면 **A4 용지 모양의 미리보기**로 열리고, 버튼 한 번으로 **PDF** 또는 **Word(.docx)** 로 저장하는 Chrome / Brave 확장 프로그램입니다.
수식과 표는 물론 **그림까지** Word 에 그대로 들어가고, 인터넷 없이 동작합니다.

> **md 파일은 AI가 작성 편집하는 것을 원칙으로 합니다.** ChatGPT, Claude 등이 써 준 마크다운을 가장 편하게 보고 문서로 바꾸는 데 맞춘 뷰어입니다.

기존 Chrome 마크다운 뷰어 확장 프로그램은 대부분 **Word 내보내기와 그림 기능이 없지만**, 이 뷰어는 **둘 다 됩니다.**

## 기능

- **A4 용지 모양 미리보기**: 제목, 표, 굵은 글씨, 하위 목록, 인용구, 수식
- **수식**: AI가 생성한 LaTeX(라텍스) 수식 인식 — `$...$`, `$$...$$`, `\( ... \)`, `\[ ... \]`
- **PDF로 저장**: 인쇄창의 "PDF로 저장" 사용 (Ctrl+P 동일). 저장 파일명은 `.md` 파일 이름 기준 (`보고서.md` → `보고서.pdf`)
- **docx로 저장**: 수식은 Word 수식(OMML)으로, 표는 Word 표로, 그림은 실제 그림으로 변환 (`보고서.md` → `보고서.docx`)
- **그림 내장**: 그림이 md 파일 안에 들어가서 파일 하나만 옮기면 됩니다
- **수정해도 보던 위치 유지**: 에디터에서 저장한 뒤 **F5** 를 누르면 바뀐 부분만 다시 그리고, 보이지 않는 위쪽을 고쳐서 길이가 바뀌어도 같은 내용이 보입니다
- **주석 숨김**: `<!-- 주석 -->` 과 `[//]: # (...)` 줄은 화면·PDF·Word 에 나오지 않음
- **오프라인**: docx, JSZip, MathJax 를 확장 안에 포함. 파일은 PC 안에서만 읽으며 외부로 전송하지 않습니다

## 설치 (약 2분)

스토어 등록 버전이 아니라 **"압축해제된 확장 프로그램"** 으로 설치합니다.

1. 이 저장소의 **Code → Download ZIP** 으로 받아 **영구적인 위치**에 압축을 풉니다. 설치 후에는 폴더를 지우거나 옮기면 안 됩니다.
2. 주소창에 입력: Chrome `chrome://extensions` / Brave `brave://extensions` / Edge `edge://extensions`
   (`chrome://` 주소는 링크로 열 수 없으니 주소창에 직접 입력하세요)
3. 오른쪽 위 **개발자 모드** 켜기
4. **압축해제된 확장 프로그램을 로드합니다** → `manifest.json` 이 들어 있는 폴더 선택
5. **MD 뷰어 → PDF / Word** 의 **세부정보**에서 **"파일 URL에 대한 액세스 허용"** 켜기 (필수)
6. 탐색기에서 `.md` 우클릭 → **연결 프로그램** → Chrome(또는 Brave) → **항상 사용**

이제 `.md` 파일을 더블클릭하면 미리보기가 열립니다.

## 사용

툴바: **MD 뷰어 안내 · 확장 프로그램 안내 · ↻ 새로고침 · PDF로 저장 · docx로 저장**

| 하고 싶은 일 | 방법 |
|---|---|
| 파일 보기 | `.md` 더블클릭 |
| 수정 내용 반영 | 에디터에서 저장 → 뷰어 탭에서 **F5** |
| PDF로 저장 | **PDF로 저장** → 인쇄창 대상 "PDF로 저장" |
| Word로 저장 | **docx로 저장** |
| 경로로 열기 | 툴바의 확장 아이콘 → "파일 경로로 열기" |
| 사용법 · AI 전달용 설명글 | **MD 뷰어 안내** |
| 설치 · 관리 · 업데이트 | **확장 프로그램 안내** |

## AI 로 md 작성 · 그림 넣기

1. **MD 뷰어 안내** → **📋 설명글 복사 (AI 전달용)** 를 눌러 AI 대화창에 **붙여넣고 보냅니다** (파일에는 넣지 않습니다)
2. AI 에게 "○○ 보고서를 md 로 써 줘", "이 그림을 ○○ 제목 밑에 넣어줘" 처럼 요청합니다
3. AI 가 돌려준 **전체 내용**을 `.md` 로 저장하면 뷰어에서 열립니다

그림은 본문에 그림 자리와 캡션, 파일 맨 아래에 그림 데이터(Base64)가 들어갑니다.

```
본문 (제목 바로 밑)
![LLC 공진 파형][회로도1]
*그림 1. LLC 공진 파형*

파일 맨 아래
<!-- [그림 데이터] 아래에 참조 정의만 둘 것 -->
[회로도1]: data:image/jpeg;base64,/9j/4AAQ....
```

- 그림을 줄이고 Base64 로 바꾸는 작업은 AI 의 **코드 실행 기능**이 필요합니다. 설명글에는 "못 하면 값을 지어내지 말고 알려 달라"는 문구가 들어 있습니다
- 그림 데이터 줄은 반드시 **한 줄**이어야 하고, 외부 주소(URL) 그림은 지원하지 않습니다
- Word 로 저장할 때 PNG 가 아닌 그림은 PNG 로 변환해 넣고, 본문 폭에 맞게 줄입니다

## 문제 해결

- **빈 화면 / "파일을 열 수 없습니다"**: 설치 5번의 "파일 URL에 대한 액세스 허용"이 꺼져 있는 경우가 대부분입니다
- **더블클릭하면 다운로드만 됨**: 설치 6번의 연결 프로그램이 브라우저로 지정되어 있는지 확인하세요
- **다른 Markdown Viewer 계열 확장과 충돌**할 수 있으니 하나는 제거하세요
- **Brave 에서 PDF 저장 파일명이 비어 있으면** 저장창에서 직접 입력하세요
- **업데이트**: 새 버전을 같은 폴더에 덮어쓴 뒤 `chrome://extensions` 에서 확장 카드의 ↻ 를 누르세요

## 구성

| 파일 | 역할 |
|---|---|
| `manifest.json` | Manifest V3 설정 (`webNavigation` + `file:///*` 호스트 권한) |
| `background.js` | `file://...md` 이동을 `viewer.html` 로 가로챔 / 아이콘 클릭 시 `help.html` |
| `viewer.html` `viewer.css` `viewer.js` | 뷰어 화면, 스크롤 위치 복원, PDF/docx 버튼, 안내창 |
| `core.js` | LaTeX 파서 · OMML 변환 · 마크다운 파서 · 그림 처리 · docx 생성 · AI 전달용 설명글 |
| `mathjax-config.js` | MathJax 설정 (확장 CSP 때문에 인라인 스크립트 금지 → 별도 파일) |
| `help.html` `help.js` | 설정 안내, 파일 경로로 열기 |
| `lib/` | docx 8.5.0 · JSZip 3.10.1 · MathJax 3.2.2 (로컬 내장) |
