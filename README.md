# MD 뷰어 → PDF / Word

마크다운(`.md`) 파일을 **A4 용지 모양의 PDF 미리보기**로 보여주고, 버튼 한 번으로 **PDF** 또는 **Word(.docx)** 로 저장합니다.
수식, 표, 인용구, 번호·하위 목록과 **파일 안에 직접 넣는 그림(Base64)** 을 지원하고, 인터넷 없이 동작합니다.

탐색기에서 `.md` 를 **더블클릭**하면 바로 열리는 Chrome / Brave 확장 프로그램입니다.

## 기능

- A4 용지 모양 미리보기 (제목, 표, 굵은 글씨, 하위 목록, 인용구)
- **수식**: `$E=mc^2$`, `$$ ... $$`, `\( ... \)`, `\[ ... \]` — Word 로 저장하면 Word 수식(OMML)으로 변환
- **PDF로 저장**: 인쇄창의 "PDF로 저장" 사용 (Ctrl+P 동일). 저장 파일명은 `.md` 파일 이름 기준 (`시험.md` → `시험.pdf`)
- **docx로 저장**: 수식·표·그림 포함 (`시험.md` → `시험.docx`)
- **파일을 고치면 바로 반영, 보던 위치 유지**
  - 에디터에서 저장한 뒤 뷰어 탭에서 **F5**
  - 보이지 않는 위쪽을 고쳐서 길이가 바뀌어도 보던 내용이 그대로 보입니다
- **그림 삽입 기능 안내** 버튼: AI(ChatGPT, Claude 등)로 그림을 넣고 바꾸고 지우는 방법과 **AI 지시서(복사 버튼)** 제공
- `<!-- 주석 -->` 과 `[//]: # (...)` 줄은 화면·PDF·Word 에 나오지 않음

## 설치 (약 2분)

스토어 등록 버전이 아니라 **"압축해제된 확장 프로그램"** 으로 설치합니다.

1. 이 저장소의 **Code → Download ZIP** 으로 받아 **압축을 풉니다.** 설치 후에는 폴더를 지우거나 옮기면 안 되니, 영구적인 위치에 풀어 두세요.
2. 주소창에 입력: Chrome `chrome://extensions` / Brave `brave://extensions`
3. 오른쪽 위 **개발자 모드** 켜기
4. **압축해제된 확장 프로그램을 로드합니다** → `manifest.json` 이 들어 있는 폴더 선택
5. **MD 뷰어 → PDF / Word** 의 **세부정보**에서 **"파일 URL에 대한 액세스 허용"** 켜기 (필수)
6. 탐색기에서 `.md` 우클릭 → **연결 프로그램** → Chrome(또는 Brave) → **항상 사용**

이제 `.md` 파일을 더블클릭하면 미리보기가 열립니다.

## AI 로 그림 넣기

`md 파일은 AI가 작성 편집하는 것을 원칙으로 합니다.` 그림은 파일 안에 Base64 로 직접 넣습니다.

```
본문 (제목 바로 밑)
![LLC 공진 파형][회로도1]
*그림 1. LLC 공진 파형*

파일 맨 아래
<!-- [그림 데이터] 아래에 참조 정의만 둘 것 -->
[회로도1]: data:image/jpeg;base64,/9j/4AAQ....
```

1. 뷰어의 **그림 삽입 기능 안내** 버튼 → **AI 지시서 복사** → AI 대화창에 붙여넣고 전송 (파일에는 넣지 않습니다)
2. AI 에게 `.md` 와 그림을 주고 "○○ 제목 밑에 이 그림 넣어줘" / "그림 2를 이걸로 바꿔줘" / "그림 3 삭제해줘" 요청
3. AI 가 돌려준 전체 내용으로 `.md` 를 덮어쓰고 저장 → 뷰어에서 반영

- 그림 줄이기·Base64 변환은 AI 가 **코드 실행 도구**로 해야 합니다. 지시서에는 "못 하면 값을 지어내지 말고 알려 달라"는 문구가 들어 있습니다.
- 그림 데이터 줄은 반드시 **한 줄** 이어야 합니다. 외부 주소(URL) 그림은 지원하지 않습니다.
- Word 로 저장할 때 PNG 가 아닌 그림은 PNG 로 변환해 넣고, 본문 폭에 맞게 줄입니다.

## 문제 해결

- **빈 화면 / "파일을 열 수 없습니다"**: 설치 5번의 "파일 URL에 대한 액세스 허용"이 꺼져 있는 경우가 대부분입니다.
- **더블클릭하면 다운로드만 됨**: 6번의 연결 프로그램이 브라우저로 지정되어 있는지 확인하세요.
- **다른 Markdown Viewer 계열 확장과 충돌**할 수 있으니 하나는 제거하세요.
- **Brave 에서 PDF 저장 파일명이 비어 있으면** 저장창에서 직접 입력하세요.

## 구성

| 파일 | 역할 |
|---|---|
| `manifest.json` | Manifest V3 설정 (`webNavigation` + `file:///*` 호스트 권한) |
| `background.js` | `file://...md` 이동을 `viewer.html` 로 가로챔 / 아이콘 클릭 시 `help.html` |
| `viewer.html` `viewer.css` `viewer.js` | 뷰어 화면, 스크롤 위치 복원, PDF/docx 버튼, 그림 삽입 안내창 |
| `core.js` | LaTeX 파서 · OMML 변환 · 마크다운 파서 · 그림 처리 · docx 생성 · AI 지시서 문구 |
| `mathjax-config.js` | MathJax 설정 (확장 CSP 때문에 인라인 스크립트 금지 → 별도 파일) |
| `help.html` `help.js` | 설정 안내, 파일 경로로 열기 |
| `lib/` | docx 8.5.0 · JSZip 3.10.1 · MathJax 3.2.2 (로컬 내장) |

## 참고

- 지원 환경: Windows, Chrome / Brave / Edge (Chromium 계열)
- 마크다운 파일과 그림은 PC 안에서만 처리되며 외부로 전송하지 않습니다.
