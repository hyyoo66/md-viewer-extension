MD 뷰어 (독립형)  -  확장 프로그램 없이 HTML 하나로 동작
=====================================================
사용
 1. md_viewer.html 을 크롬(또는 엣지)으로 연다.   ※ lib 폴더가 같은 위치에 있어야 한다 (폴더째 보관)
 2. .md 파일을 창에 끌어다 놓는다.  (또는 [파일 열기])
 3. [PDF로 저장]  인쇄창 → 대상 "PDF로 저장" (Ctrl+P 동일)  /  [docx로 저장]  수식·표 포함 Word 문서
    저장 파일명은 .md 파일 이름 기준 (시험.md → 시험.pdf / 시험.docx)

자동 새로고침 (Chrome / Edge)
 - 에디터에서 .md 를 저장하면 1초 안에 자동으로 다시 그려지고, 보던 위치가 유지된다 (F5 불필요)
 - F5 로 페이지를 새로고침해도 이전 파일을 이어서 연다.
   브라우저가 파일 접근 권한을 다시 물으면 [이전 파일 이어서 열기] 를 누른다.
 - 핸들을 못 얻는 브라우저(Firefox 등)에서는 열 때 한 번만 그린다. 갱신하려면 파일을 다시 끌어다 놓는다.

그림
 - md 안의 Base64 그림 ( ![설명][이름]  +  맨 아래 [이름]: data:image/jpeg;base64,... ) 지원
 - [그림 삽입 기능 안내] 버튼 → AI 로 그림을 넣는 방법 + AI 지시서 복사
 - <!-- 주석 --> 은 화면·PDF·docx 에 나오지 않음

확장 프로그램 버전(chrome_extension)과 같은 변환 코드를 쓴다 (core.js 를 그대로 내장).
라이브러리: docx 8.5.0 (MIT), JSZip 3.10.1 (MIT), MathJax 3.2.2 (Apache-2.0)  -  lib 폴더
