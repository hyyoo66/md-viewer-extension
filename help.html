MD 뷰어 → PDF / Word

로컬 .md 파일을 열면 PDF 형태로 미리 보고, PDF 또는 Word(.docx)로 저장합니다.

① 파일 URL 접근 상태

현재: 확인 중…
  1. 아래 버튼으로 확장 프로그램 관리 화면을 엽니다.
  2. "MD 뷰어 → PDF / Word" 상세 정보에서 "파일 URL에 대한 액세스 허용"을 켭니다.

브라우저가 직접 열 수 없는 주소라면 주소창에 chrome://extensions (Brave는 brave://extensions)를 입력해 이동하세요.

② .md 파일 더블클릭으로 열기

  1. 탐색기에서 .md 파일을 우클릭 → 연결 프로그램 → Chrome(또는 Brave) 선택 → "항상 사용"
  2. 이후 .md 파일을 더블클릭하면 브라우저가 열리면서 이 뷰어로 표시됩니다.

③ 사용 방법

  • 편집은 외부 에디터로 하고, 저장한 뒤 이 탭에서 F5를 누르면 바뀐 내용이 다시 렌더링됩니다. 보던 자리는 그대로 유지됩니다.
  • PDF로 저장: 인쇄 창에서 대상을 "PDF로 저장"으로 선택하세요. (Ctrl+P도 동일)
  • .docx 다운로드: Word 문서(수식·표 포함)를 다운로드 폴더에 저장합니다.
