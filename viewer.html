그림 삽입 기능 안내

md 파일은 AI가 작성 편집하는 것을 원칙으로 합니다.

이 뷰어는 .md 파일 안에 그림을 직접 넣어 두는 방식(Base64)을 지원합니다. 그림을 넣고 바꾸고 지우는 편집은 AI가 해 주며, 아래 AI 지시서를 AI에게 먼저 붙여넣으면 AI가 그 방법을 알고 같은 방식으로 처리합니다. (지시서는 .md 파일에 넣지 않습니다.)

사용 순서

  1. 아래 [AI 지시서 복사]를 눌러, AI(ChatGPT, Claude 등) 대화창에 붙여넣고 전송합니다. AI가 "이해했습니다"라고 답하면 준비가 끝난 것입니다. (새 대화를 시작할 때마다 한 번)
  2. 이어서 .md 파일과 넣을 그림을 AI에게 주고(첨부 또는 붙여넣기) 이렇게 요청합니다.
    • "○○ 제목 밑에 이 그림 넣어줘"
    • "그림 2를 이걸로 바꿔줘"  /  "캡션도 바꿔줘"
    • "그림 3 삭제해줘"
  3. AI가 돌려준 전체 파일 내용으로 .md 파일을 덮어쓰고 저장합니다.
  4. 이 뷰어 탭에서 F5를 누르면 그림이 반영되고, 보던 위치는 그대로 유지됩니다.

파일에 들어가는 모양

본문 (제목 바로 밑)
![LLC 공진 파형][회로도1]
*그림 1. LLC 공진 파형*

파일 맨 아래
<!-- [그림 데이터] 아래에 참조 정의만 둘 것 -->
[회로도1]: data:image/jpeg;base64,/9j/4AAQ....
  • 그림은 가로 1000px 이하 JPG로 줄여 Base64로 파일 맨 아래에 모입니다. 그림 번호는 AI가 순서대로 다시 매깁니다.
  • 그림 바로 아래 *그림 N. 설명* 줄은 가운데 정렬 캡션으로 표시됩니다.
  • .md 파일 하나에 그림이 모두 들어 있어 파일을 옮겨도 그림이 따라갑니다. 대신 파일 크기가 커집니다.
  • 아래쪽 그림 데이터 줄은 반드시 한 줄이어야 합니다. 외부 주소(URL) 그림은 지원하지 않습니다.
